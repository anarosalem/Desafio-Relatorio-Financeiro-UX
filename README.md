📊 Relatório Financeiro com Foco na Experiência do Usuário (UX)

📝 Sobre o Projeto

Este repositório contém a solução para o "Desafio de Projeto - Atualizando Relatório Financeiro com Foco na Experiência do Usuário". O objetivo principal foi refatorar o primeiro relatório criativo desenvolvido, aplicando conceitos de design visual e usabilidade para melhorar a forma como os usuários interagem e interpretam os dados financeiros.


🎯 Objetivo

Modificar o relatório financeiro original, priorizando a Experiência do Usuário (UX). A reformulação levou em consideração a estética, a clareza da informação e a fluidez na leitura dos dados, aplicando (e quebrando de forma consciente) regras de design para trazer mais criatividade e impacto visual ao dashboard.

🎨 Princípios de Design Aplicados

Durante a adequação do relatório (que é composto por 3 páginas no total), os seguintes conceitos foram explorados:

Posicionamento: Organização estratégica dos visuais para guiar a leitura de forma intuitiva, mantendo as informações mais importantes em áreas de maior foco.

Contraste: Uso de cores e tons para destacar métricas essenciais e facilitar a distinção entre diferentes categorias de dados, sem cansar a visão do usuário.

Proporção Áurea: Aplicação de conceitos de proporção para harmonizar os tamanhos dos gráficos e tabelas, garantindo um layout equilibrado e agradável.

Segmentação dos Dados: Agrupamento lógico das informações (como a criação da matriz de descrição de vendas e a modificação do gráfico de área) para que os usuários encontrem facilmente o que procuram.
